## Time Windows

| Action | Deadline |
|--------|----------|
| CRA reinvestigation | 30 days (+15 if new info) |
| FDCPA debt validation dispute | 30 days from validation notice |
| FCBA billing error notice | 60 days from statement with error |
| FCBA creditor resolution | 2 billing cycles / 90 days max |
| ECOA adverse action notice | 30 days from completed application |
| FCRA free report after adverse action | 60 days |

## Recipient Routing

| Dispute target | Send to |
|----------------|---------|
| Credit report item | CRA dispute address + furnisher (optional direct §623) |
| Collection account | Debt collector |
| Credit card charge | Creditor billing inquiry address on statement |
| Credit denial | Entity that took adverse action |
