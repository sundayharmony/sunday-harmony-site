**Creator:** Stephen Smith — *Success with Stephen*

> **Not legal advice / not financial advice.** Ranking is the creator’s opinion for education.

---

## 1. Deep summary

Ranks popular credit moves from **F (can hurt)** to **S (highest leverage)**, so staff/clients stop wasting effort on low-impact or harmful tactics.

**Meta-rule:** Identify the *largest* problem on the actual 3-bureau report first. Don’t stack every tactic at once. Give strategies time. Pull ACR.com (weekly free pulls noted at recording).

---

## 2. Tier list (as taught)

| Tier | Strategy | Why (video) |
|------|----------|-------------|
| **F** | Closing a healthy old credit card “because paid off / unused” | Can spike utilization by cutting available credit; hurts without spending more. Prefer keep open (small autopay) or product-change to no-AF. Close only if spending risk outweighs score. Inactivity closure risk → tiny recurring charge. |
| **C** | Waiting / time alone | Recency matters; negatives fade; positives age. Passive 7 years clears a lot — but passive; not a complete plan. |
| **C** | “Always report $0 on every card” as a score maximizer | Myth mix-up: very low reported utilization helps; reporting **all zeros** can hurt ~15–20 pts vs small reported balances. Optimize: allow statement to post small %, pay in full by due date to avoid interest. Mostly maintenance / pre-app once already 2–3%. |
| **B** | Dispute / remove hard inquiries | ~5–10 pts each (Experian cite); scoring impact ~12 months though listed ~2 years. Matters more for approval optics with many recent inquiries than for huge point jumps. |
| **B** | Credit builder loan / secured card | Foundation for thin/rebuild files; slow; less valuable if already rich healthy file. |
| **B** | Opening a new account (strategic) | Short-term inquiry + age hit; long-term available credit can cut overall utilization; feeds payment history (35%) + amounts owed (30%). Be selective. |
| **B** (with warning) | Purchased tradelines | Temporary AU boost; costly; 1–3 cycles; some models/lenders discount; not a substitute for primary history. |
| **A** | Trusted authorized user on excellent card | Can add age/limit/history/utilization quickly for thin files; mortgage underwriters may discount AU-heavy profiles — supplement, don’t replace primary accounts. |
| **A** | Removing major derogatories (charge-offs, collections, late payments) | Recent/serious derogs can cost 100+ pts on strong scores; cross-bureau review for errors/duplicates/mismatches; persistence required; DIY tools (Rising) vs expensive companies. |
| **S** | On-time payments (autopay safety net) | Payment history is the base; nothing compensates for ongoing delinquencies. Contact lenders *before* late; hardship/due-date changes beat a 30-day mark. |

### Order of operations (video close)
- High balances → utilization tactics  
- Missed due dates → stabilize payments first, then dispute documented errors  
- Thin file → secured/builder/trusted AU  
- Already healthy → statement timing, selective new credit  

**Don’t:** close old card + spam apps + buy tradeline + dispute accurate info because someone promised +200.

## 4. MANUAL checklist

- [ ] In product: identify top constraints (payment history vs utilization vs inquiries vs thin file vs public record).
- [ ] **MANUAL** Stabilize on-time payments / autopay before fancy tactics (**S tier**).
- [ ] In product: dispute inaccurate/unverifiable **A-tier** derogs with evidence.
- [ ] **MANUAL** Hard inquiries: only chase when recent/numerous or blocking apps; don’t expect huge point swings.
- [ ] **MANUAL** Do **not** close seasoned no-AF cards for “cleanup” (**F tier**).
- [ ] **MANUAL** Thin-file build (secured/builder/trusted AU) outside product.
- [ ] **MANUAL** Purchased tradelines: disclose risks; temporary; optional last resort.
- [ ] **MANUAL** Utilization / statement timing / new cards: client banking actions; re-pull reports after updates.
- [ ] **MANUAL** Pull all three reports; don’t guess the bottleneck.

### Product does not
1. Rank client actions F–S automatically (this doc is the rubric).
2. Open/close cards, buy tradelines, or set autopay.
3. Guarantee 200-point gains.
4. Replace payment discipline.
