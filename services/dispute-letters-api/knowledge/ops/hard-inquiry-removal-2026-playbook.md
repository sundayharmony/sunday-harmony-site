# Hard inquiry removal (2026 method update) — study notes + ops checklist

**Source video:** [Remove Hard Credit Inquiries FAST!! 2026 (METHOD UPDATE)](https://www.youtube.com/watch?v=ocEbe4g9aq8)  
**Creator:** Stephen Smith — *Success with Stephen*

> **Not legal advice.** Educational ops notes only. Staff must verify whether an inquiry was truly unauthorized before treating it as identity theft. Filing false FTC identity-theft reports is unlawful. Outcomes are never guaranteed.

## 1. Deep summary

### Goal
Show a **2026-updated** path to challenge **unauthorized hard inquiries** when older shortcuts (especially **BBB**) no longer work, and when **CFPB** capacity is uncertain after mid-2025 funding cuts.

### Core thesis
1. Hard inquiries need consumer authorization under FCRA permissible-purpose rules; unrecognized pulls are the target — not every inquiry you later regret.
2. **BBB** inquiry method is dead; **CFPB** still accepts complaints and still worked in his tests.
3. Fastest workable stack he demonstrates: pull precise 3-bureau inquiry data → **identitytheft.gov** FTC Identity Theft Report (affidavit) listing the inquiries → **CFPB** complaint to each bureau with ID packet + report + affidavit.
4. Precision of **creditor name + date + bureau** matters; mismatches let bureaus close as “cannot locate.”
5. He personally placed **three hard inquiries per bureau**, documented removal timing, and notes Experian sometimes needs a second submit.
6. Phone / certified-mail remain fallbacks when CFPB is slow (esp. TransUnion).

### Method at a glance

```
ACR.com and/or Rising (exact inquiry name + date + bureau)
  → identitytheft.gov Identity Theft Report
      (list up to 3 inquiries on form; extras in personal statement)
  → Download one-time FTC affidavit PDF
  → CFPB complaint: credit reporting → inquiries you don't recognize
  → Attach: DL + SSN card + affidavit + credit report page showing inquiries
  → Address Experian + Equifax + TransUnion in one multi-company complaint when names match
  → Track: Experian ~7–10d · Equifax ~7–14d (often faster) · TransUnion ~30d
  → Fallback: phone (Experian often quick) or certified letter
```

## 2. Beat-by-beat detail

### 2.1 Why a 2026 update
- July **2025** budget cut (~**50%** CFPB funding) → staff reductions, enforcement delays, political pressure to shrink the bureau.
- CFPB **did not shut down**; consumers can still file.
- His earlier **BBB** hard-inquiry method **no longer works**.
- Prior CFPB successes still count as a valid channel; procedures and attachment expectations evolved — hence the update.
- Platforms change; rules (FCRA) do not — stay current on *how* you deliver the dispute.

### 2.2 Disclaimers he stresses
- Not a financial adviser / not a credit-repair specialist; will not do paid repair work.
- Free educational content; watch end-to-end (comment volume is high).

### 2.3 Get the right inquiry data first
| Source | Role |
|--------|------|
| **annualcreditreport.com** | Only federally authorized free official reports; weekly pulls noted at recording. True creditor name, date, bureau as the bureau sees them. |
| **Rising** (paid / $1 trial cited) | Tri-merge view; easier to see which inquiries hit which bureau and date mismatches; real-time removal notifications. |

**Precision rule:** wrong name/date in the dispute → bureau may close without correcting. Pull fresh reports before filing.

### 2.4 FTC Identity Theft Report (`identitytheft.gov`)
Walkthrough he demonstrates:

1. Report identity theft → **Yes**.
2. Account type: **always choose credit card** in his method — even if the inquiry was auto, bank, etc. (his explicit instruction; staff should still exercise judgment).
3. Path: open a **fraudulent credit card account**.
4. **Theft details:** leave blank / bypass.
5. **Your information:** name, phone, email, DOB, current mailing address, time at address. Leave optional trailing defaults as **No**.
6. **Phone verification pain:** if codes stop arriving after multiple filings → clear cache, new browser, incognito, other device, other browser, **Google Voice**, or wait 1–2 days.
7. **Suspect information:** No, not at this time.
8. **Additional information:**
   - Received a copy of credit report? **Yes**
   - Fraudulent accounts on report? **No** (for inquiry-only path)
   - Personal info wrong? **None of the above**
9. Form allows listing **up to three** unrecognized inquiries (name + date). More go in the **personal statement**.
10. Personal statement: short, own words — e.g. “Please remove this hard inquiry… I don’t recognize these.” Avoid identical copy-paste spam across many consumers.
11. Review → **Finalize** → **No thanks, submit without an account** (twice if prompted).
12. **Download immediately** — one-time copy; leaving the page forces a full redo.

### 2.5 CFPB complaint (`consumerfinance.gov`)
1. Start a new complaint (create/login to account).
2. Product: **Credit reporting or other personal consumer reports** → **Credit report**.
3. Issue: **Credit inquiries on your report that you don’t recognize**.
4. Already tried to fix? **Yes**. Requested information from company? **Yes**. Company provided it? **No**.
5. **What happened:** unauthorized / unrecognized hard inquiries; list name+date; can paste from affidavit; use own wording.
6. **Fair resolution:** remove the hard inquiry(ies). Do not need to publish the narrative.
7. **Attachments (2026 emphasis — he says this changed):**
   - Driver’s license / government photo ID
   - Social Security card
   - FTC Identity Theft Report / affidavit
   - Credit report excerpt showing the inquiry (name must match the report **exactly**)
8. Without the full ID set + matching report, he observes removals often fail.
9. **Multi-bureau in one complaint:** if the same inquiry listing applies across bureaus, add Experian, Equifax, and TransUnion as companies in the same flow (check boxes, last-4 SSN, DOB, name as on report each time). Prefer the primary CRA company name that comes up first.
10. Complaint on behalf of: always **Myself**.
11. Review and submit (he stops before actually submitting on camera).

### 2.6 Observed timelines (his three-inquiry-per-bureau test)
| Bureau | Rough timing | Notes |
|--------|--------------|-------|
| **Experian** | ~**7–10 days** | Sometimes one inquiry needed a **second** submit; same window after resubmit. Phone can work in ~24 hours in his/others’ experience. |
| **Equifax** | ~**7–14 days** (often **~3–5**) | Generally faster in his tests. |
| **TransUnion** | ~**30 days** | Slowest. Phone results mixed; may place **fraud alert** that propagates to all three — then you must unwind it. Certified mail packet can be faster when CFPB stalls. |

### 2.7 Fallbacks
- **Certified letter** with the same docs (affidavit + IDs + report) to the slow bureau.
- **Phone dispute** — Experian Special Services / fraud-style desk often fastest; Equifax sometimes; TransUnion mixed.
- If offered a freeze/fraud alert during phone disputes and the client needs new credit soon, weigh declining vs security needs.

### 2.8 Complementary cautions (from his related hard-inquiry content / good practice)
- Prefer disputing inquiries the client **did not authorize**; legitimate applications they signed for are weak FCRA identity-theft claims.
- Avoid disputing the inquiry that opened an **account the client wants to keep** — some consumers report account friction when the originating inquiry is attacked.
- Score impact of one hard pull is usually small (~few points); many recent inquiries matter more for **approvals** than for huge point swings (see tier-list playbook — **B** tier).
- Soft inquiries are not the target.

## 4. MANUAL checklist

### Decide whether to use this path
- [ ] In product: list hard inquiries by bureau; note dates and creditor names exactly as reported.
- [ ] **MANUAL** Client confirms which pulls were **not** authorized (vs applications they made).
- [ ] **MANUAL** Skip / caution inquiries tied to open accounts the client wants to keep.
- [ ] Prefer product **letters** when portal risk is high or client won’t file FTC identity-theft paperwork.

### If using the 2026 portal method
- [ ] **MANUAL** Pull ACR.com (and/or Rising) so names/dates match bureau files.
- [ ] **MANUAL** Complete `identitytheft.gov` report; download affidavit immediately.
- [ ] **MANUAL** File CFPB complaint(s) with DL + SSN card + affidavit + report pages; match names exactly.
- [ ] **MANUAL** Multi-select all three CRAs when the same facts apply.
- [ ] **MANUAL** Calendar follow-ups: Experian ~10d, Equifax ~14d, TransUnion ~30d; resubmit stubborn Experian items.
- [ ] **MANUAL** If TransUnion stalls: certified mail packet and/or cautious phone path (watch for unwanted fraud alerts).
- [ ] In product: after removals, re-upload/re-analyze reports; update rounds / progress for the client.

### Product does not
1. Submit FTC identity-theft affidavits or CFPB multi-company inquiry complaints.
2. Place or remove bureau fraud alerts / freezes.
3. Call Experian Special Services.
4. Treat every hard inquiry as automatically dispute-worthy.
5. Promise 7-day removals.
