# Legal Knowledge Base — Credit Letter Automation

This directory contains ingested federal consumer credit statutes used as the authoritative source for credit dispute and debt collection letter work in this project.

## Disclaimer

**This is not legal advice.** The materials here are public statutory texts compiled for reference. Laws change, state laws may provide additional rights, and individual circumstances vary. Users are responsible for reviewing and finalizing any correspondence before sending. The AI agent must cite from these files, not from memory.

## Citation Convention

Always use **dual citations** when referencing statutes in letters:

- FCRA: `FCRA §611 (15 U.S.C. §1681i)`
- FDCPA: `FDCPA §809 (15 U.S.C. §1692g)`
- FCBA: `15 U.S.C. §1666`

Prefer the FTC March 2026 FCRA compendium for FCRA text when formatting differs from the U.S. Code.
